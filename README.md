# Modul 1B: Website DNN (hasil dari Modul 1A)

**Belum ada model pretrained dalam paket ini.** Setelah menjalankan Modul_1A, salin `model_sentimen_brimo.pkl` dan `model_info.json` ke folder ini.

Jalankan:
```powershell
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Dataset BRImo tersedia di folder ini untuk tombol download contoh. Website membangkitkan sampel CSV saat tombol ditekan. Tidak ada CSV contoh siap jadi yang perlu disimpan.
